# 🧠 Antigravity Data & BI Skills Suite

Suite oficial de **Custom Agent Skills** de alto rendimiento para **Antigravity (Google DeepMind)**, desarrollada por **Rubén David Barrios Bello** (Data Analyst & BI Developer).

Este repositorio centraliza las habilidades, directrices metodológicas, árboles de decisión, scripts utilitarios y plantillas corporativas que dotan al asistente de IA con el conocimiento exacto y acreditado de mi stack tecnológico y certificaciones profesionales.

---

## 📚 Estructura de las Skills

1. **`digital-analytics-ga4-gtm`** (Analytics Way): Plan de medición, GA4, GTM Web/Server-Side, E-commerce tracking, Consent Mode v2 y Looker Studio.
2. **`python-sql-data-automation`** (Talento Tech - Min. Educación): Core Python, modularidad, persistencia y operaciones CRUD SQLite3 seguras contra SQL Injection.
3. **`bi-consulting-looker-studio`** (Talento Tech - Min. Educación): Consultoría BI, Google Sheets avanzado, reducción de carga cognitiva y storytelling de datos.
4. **`python-data-analytics-eda`** (Talento Tech - Min. Educación): EDA con NumPy, Pandas, correlaciones y visualización avanzada con Seaborn, Matplotlib y Plotly.
5. **`machine-learning-business-analytics`** (Talento Tech - Min. Educación): Scikit-Learn pipelines, modelos predictivos supervisados y clustering K-Means.
6. **`powerbi-devops-fabric`**: Formato PBIP, Git Flow para BI, canalizaciones CI/CD en Azure DevOps con Service Principals y despliegue continuo en Microsoft Fabric (DEV/TEST/PROD).
7. **`dbt-bi-data-modeling`** (Enterprise Retail Project): Modelado dimensional Kimball en dbt Core, particionado/clustering en BigQuery, FinOps y data tests.
8. **`powerbi-developer-pbip`** (Enterprise Retail Project): TMDL UTF-8 sin BOM, DAX ejecutivo, motor visual HTML/CSS/SVG con efecto 3D flip y canvas 1920x1080.
